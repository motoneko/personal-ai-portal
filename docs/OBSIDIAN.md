# Obsidian Sync：只读接入方案（尚未启用）

目标地址 `/notes/`，首页和功能导航均提供入口；必须登录私人空间后浏览和搜索。

官方 [Obsidian Headless](https://obsidian.md/help/sync/headless) 已支持在 Linux 服务器同步 Obsidian Sync，无需桌面应用持续在线。目前为 open beta，需要有效的 Sync 订阅。

建议的数据路径：Obsidian Sync → 独立 Headless 同步进程 → 服务器专用笔记目录 → Portal 只读挂载 → 目录浏览、Markdown 阅读、全文搜索。

## 准备工作

1. 确定远程库名称和需要排除的私人目录。
2. 在服务器终端完成 `ob login`，不在公开仓库、网页或聊天中存放登录密码、token、加密口令。
3. 对全新专用目录执行 `ob sync-setup`。启用端到端加密的库需要在该设备输入加密口令。
4. **首次运行同步之前**配置 `ob sync-config --mode mirror-remote`，使该目录只下载云端内容；关闭配置同步，并按需排除附件类型和目录。不要在已有桌面 Sync 的目录运行 Headless。
5. 运行 `ob sync --continuous`，单独限制同步进程资源。Portal 用只读卷访问同步目录。

## 网页范围

- 目录、标题和全文搜索，Markdown 只读展示，后续可支持双链跳转及图片。
- 过滤 `.obsidian`、隐藏文件、路径穿越和指向库外的符号链接；笔记 HTML 必须净化，脚本禁用。
- 笔记内容、搜索结果、附件均经过会话验证，禁止公开缓存。只有同步容器可写副本，Portal 没有写入接口。
- 不自动发送笔记给 AI；不提供在线编辑，不回写官方云端。
- 明确显示最后同步时间和错误状态，避免将旧副本误认为实时结果。

服务器将持有解密后的笔记副本，需要把它按私人数据管理。此文档仅为可行性方案，当前部署未安装同步客户端、未复制笔记、未添加虚假的 `/notes/` 入口。
